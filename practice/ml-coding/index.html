    ML Coding from Scratch¶

    TL;DR

    ML coding rounds ask you to implement a model, layer, loss or metric cleanly, usually in NumPy or PyTorch, while explaining shapes and trade-offs. The implementations below are tested: they live in code/ml_from_scratch.py, which includes self-tests (python code/ml_from_scratch.py), and this page includes that exact code. Practise writing each one from memory in 10–15 minutes.

    Where this fits

    Each exercise links back to its concept page. Use the Interview Playbook approach: clarify, state the approach, write the simple version, narrate shapes, test on a tiny example, then discuss improvements.

    How to approach each exercise¶

    1. Clarify: input shapes and types, edge cases (empty input, ties, all one class), and whether vectorization or a loop is expected.
    2. State the math in one or two lines before coding.
    3. Write the simple, correct version, vectorized with NumPy.
    4. Narrate shapes: "X is (n, d), w is (d,), so X @ w is (n,)."
    5. Test on a tiny example you can verify by hand.
    6. Discuss: numerical stability, complexity, regularization, and how you'd scale it.

    Linear regression¶

    Closed form via least squares, and gradient descent on MSE. Gradient: \(\frac{2}{n}X^\top(Xw + b - y)\).

    def linear_regression_normal_equation(X, y):
    """Closed form: w = (X^T X)^-1 X^T y. A bias column is added. Returns (w, b)."""
    Xb = np.hstack([X, np.ones((X.shape[0], 1))])
    theta = np.linalg.lstsq(Xb, y, rcond=None)[0]   # more stable than an explicit inverse
    return theta[:-1], theta[-1]


def linear_regression_gd(X, y, lr=0.1, epochs=1000):
    """Batch gradient descent on mean squared error. X: (n, d), y: (n,)."""
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        error = X @ w + b - y              # (n,)
        w -= lr * (2 / n) * (X.T @ error)  # dMSE/dw
        b -= lr * (2 / n) * error.sum()    # dMSE/db
    return w, b

    Say: solving with lstsq (QR/SVD) is more stable than computing \((X^\top X)^{-1}\) explicitly; the closed form costs \(O(nd^2 + d^3)\), so use gradient descent or SGD for large \(d\); scale features for gradient descent.

    Logistic regression¶

    Sigmoid of a linear score, trained on log loss. Gradient: \(\frac{1}{n}X^\top(p - y)\).

    def sigmoid(z):
    """Numerically stable sigmoid."""
    out = np.empty_like(z, dtype=float)
    pos = z >= 0
    out[pos] = 1 / (1 + np.exp(-z[pos]))
    ez = np.exp(z[~pos])
    out[~pos] = ez / (1 + ez)
    return out


def log_loss(y, p, eps=1e-12):
    p = np.clip(p, eps, 1 - eps)
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))


def logistic_regression(X, y, lr=0.1, epochs=2000, l2=0.0):
    """Gradient descent on log loss with optional L2. Labels y in {0, 1}."""
    n, d = X.shape
    w, b = np.zeros(d), 0.0
    for _ in range(epochs):
        p = sigmoid(X @ w + b)
        w -= lr * (X.T @ (p - y) / n + l2 * w)   # gradient is (p - y) x
        b -= lr * np.mean(p - y)
    return w, b

    Say: the naive 1 / (1 + exp(-z)) overflows for large negative \(z\), hence the two-branch sigmoid; clip probabilities in the loss to avoid \(\log 0\); L2 keeps weights finite on separable data; for imbalance, weight each example's gradient by its class weight.

    Softmax and cross-entropy¶

    def softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)      # subtract the max: no overflow
    e = np.exp(z)
    return e / e.sum(axis=axis, keepdims=True)


def cross_entropy_with_grad(logits, labels):
    """logits: (n, k), labels: (n,) integer classes. Returns (loss, dL/dlogits)."""
    n = logits.shape[0]
    shifted = logits - logits.max(axis=1, keepdims=True)
    log_probs = shifted - np.log(np.exp(shifted).sum(axis=1, keepdims=True))  # log-softmax
    loss = -log_probs[np.arange(n), labels].mean()
    grad = np.exp(log_probs)
    grad[np.arange(n), labels] -= 1               # p - y
    return loss, grad / n

    Say: subtracting the row maximum doesn't change softmax but prevents overflow; computing log-softmax directly avoids \(\log 0\); the gradient with respect to logits is \((p - y)/n\). The self-test checks it against finite differences.

    k-means¶

    def kmeans(X, k, iters=100, seed=0):
    """Lloyd's algorithm with k-means++ initialization. Returns (centroids, labels)."""
    rng = np.random.default_rng(seed)
    centroids = [X[rng.integers(len(X))]]
    for _ in range(1, k):                          # k-means++: spread the starting points
        d2 = np.min([((X - c) ** 2).sum(axis=1) for c in centroids], axis=0)
        centroids.append(X[rng.choice(len(X), p=d2 / d2.sum())])
    centroids = np.array(centroids)
    for _ in range(iters):
        dists = ((X[:, None, :] - centroids[None, :, :]) ** 2).sum(axis=2)  # (n, k)
        labels = dists.argmin(axis=1)
        new = np.array([X[labels == j].mean(axis=0) if np.any(labels == j) else centroids[j]
                        for j in range(k)])
        if np.allclose(new, centroids):
            break
        centroids = new
    return centroids, labels

    Say: k-means++ initialization; each iteration is \(O(nkd)\); the broadcasted distance matrix uses \(O(nk)\) memory (chunk it for large \(n\)); handle empty clusters (here: keep the old centroid; alternatives re-seed it with a far point); run several seeds and keep the lowest inertia.

    k-nearest neighbors¶

    def knn_predict(X_train, y_train, X_query, k=5):
    """Majority vote among the k nearest training points (Euclidean)."""
    d2 = ((X_query[:, None, :] - X_train[None, :, :]) ** 2).sum(axis=2)  # (m, n)
    nearest = np.argpartition(d2, kth=k - 1, axis=1)[:, :k]
    return np.array([Counter(y_train[row]).most_common(1)[0][0] for row in nearest])

    Say: argpartition finds the \(k\) smallest in \(O(n)\) per query instead of sorting; brute force is \(O(mnd)\); scale features first; for millions of points use an approximate index (HNSW, IVF); for ties, use distance weighting or an odd \(k\).

    Best decision-tree split¶

    def gini(y):
    _, counts = np.unique(y, return_counts=True)
    p = counts / counts.sum()
    return 1 - np.sum(p ** 2)


def best_split(X, y):
    """Return (feature, threshold, gain) of the best Gini split, or None if no split helps."""
    n, d = X.shape
    parent = gini(y)
    best = None
    for j in range(d):
        values = np.unique(X[:, j])
        for t in (values[:-1] + values[1:]) / 2:  # midpoints between distinct values
            left = X[:, j] <= t
            n_left = left.sum()
            child = (n_left * gini(y[left]) + (n - n_left) * gini(y[~left])) / n
            gain = parent - child
            if best is None or gain > best[2]:
                best = (j, t, gain)
    return best if best and best[2] > 0 else None

    Say: candidate thresholds are midpoints between sorted distinct values; this version is \(O(d \cdot n^2)\); sorting once per feature and sweeping with running class counts makes it \(O(d\, n \log n)\); to grow a tree, recurse on each side until a depth limit, a minimum leaf size, or no positive gain.

    Two-layer network with backprop¶

    def train_mlp(X, y, hidden=16, k=2, lr=0.5, epochs=2000, seed=0):
    """Two-layer network (ReLU hidden layer, softmax output) trained with full-batch GD."""
    rng = np.random.default_rng(seed)
    d = X.shape[1]
    W1 = rng.normal(0, np.sqrt(2 / d), (d, hidden)); b1 = np.zeros(hidden)   # He init
    W2 = rng.normal(0, np.sqrt(2 / hidden), (hidden, k)); b2 = np.zeros(k)
    for _ in range(epochs):
        Z1 = X @ W1 + b1                 # (n, h)
        A1 = np.maximum(0, Z1)
        Z2 = A1 @ W2 + b2                # (n, k)
        loss, dZ2 = cross_entropy_with_grad(Z2, y)
        dW2 = A1.T @ dZ2; db2 = dZ2.sum(axis=0)
        dA1 = dZ2 @ W2.T
        dZ1 = dA1 * (Z1 > 0)             # ReLU derivative
        dW1 = X.T @ dZ1; db1 = dZ1.sum(axis=0)
        W1 -= lr * dW1; b1 -= lr * db1
        W2 -= lr * dW2; b2 -= lr * db2
    predict = lambda Xn: (np.maximum(0, Xn @ W1 + b1) @ W2 + b2).argmax(axis=1)  # noqa: E731
    return predict, loss

    Say: He initialization for ReLU; the backward pass mirrors the forward pass (\(\partial W = A^\top \partial Z\), pass back \(\partial Z\,W^\top\), multiply by the ReLU mask); the self-test trains it on an XOR-like problem a linear model can't solve; next steps would be mini-batches, momentum or Adam, and a held-out set.

    Attention¶

    def scaled_dot_product_attention(Q, K, V, causal=False):
    """Q: (..., n, d_k), K: (..., m, d_k), V: (..., m, d_v) -> (..., n, d_v)."""
    d_k = Q.shape[-1]
    scores = Q @ np.swapaxes(K, -1, -2) / np.sqrt(d_k)
    if causal:
        n, m = scores.shape[-2:]
        scores = np.where(np.triu(np.ones((n, m), dtype=bool), k=1), -1e9, scores)
    return softmax(scores, axis=-1) @ V


def multi_head_attention(X, W_q, W_k, W_v, W_o, num_heads, causal=True):
    """X: (n, d_model); each W: (d_model, d_model)."""
    n, d_model = X.shape
    d_head = d_model // num_heads
    split = lambda T: T.reshape(n, num_heads, d_head).transpose(1, 0, 2)  # noqa: E731
    Q, K, V = split(X @ W_q), split(X @ W_k), split(X @ W_v)
    heads = scaled_dot_product_attention(Q, K, V, causal)            # (h, n, d_head)
    return heads.transpose(1, 0, 2).reshape(n, d_model) @ W_o

    Say: scale by \(\sqrt{d_k}\); mask with a large negative number before the softmax; heads are split by reshaping \((n, d)\) to \((h, n, d/h)\); the self-test checks causality (changing later tokens doesn't change earlier outputs). For a padding mask, combine a key mask with the causal mask. In PyTorch:

    import torch
import torch.nn as nn


class CausalSelfAttention(nn.Module):
    def __init__(self, d_model: int, n_heads: int):
        super().__init__()
        assert d_model % n_heads == 0
        self.n_heads, self.d_head = n_heads, d_model // n_heads
        self.qkv = nn.Linear(d_model, 3 * d_model)
        self.out = nn.Linear(d_model, d_model)

    def forward(self, x):                                   # x: (B, T, C)
        B, T, C = x.shape
        q, k, v = self.qkv(x).split(C, dim=2)
        q, k, v = (t.view(B, T, self.n_heads, self.d_head).transpose(1, 2) for t in (q, k, v))
        att = (q @ k.transpose(-2, -1)) / self.d_head ** 0.5      # (B, h, T, T)
        mask = torch.triu(torch.ones(T, T, dtype=torch.bool, device=x.device), diagonal=1)
        att = att.masked_fill(mask, float("-inf")).softmax(dim=-1)
        y = (att @ v).transpose(1, 2).contiguous().view(B, T, C)
        return self.out(y)
        # Production code would call torch.nn.functional.scaled_dot_product_attention(q, k, v, is_causal=True)

    Sampling: temperature, top-k, top-p¶

    def sample_next_token(logits, temperature=1.0, top_k=None, top_p=None, rng=None):
    """Temperature, then top-k, then top-p (nucleus) filtering, then sample one token id."""
    rng = rng or np.random.default_rng()
    if temperature == 0:
        return int(np.argmax(logits))                 # greedy
    probs = softmax(np.asarray(logits, dtype=float) / temperature)
    order = np.argsort(probs)[::-1]                    # most likely first
    keep = np.ones(len(probs), dtype=bool)
    if top_k is not None:
        keep[order[top_k:]] = False
    if top_p is not None:
        cumulative = np.cumsum(probs[order])
        cutoff = np.searchsorted(cumulative, top_p) + 1   # smallest set reaching top_p
        keep[order[cutoff:]] = False
    probs = np.where(keep, probs, 0)
    return int(rng.choice(len(probs), p=probs / probs.sum()))

    Say: temperature 0 means greedy; apply temperature before filtering; top-p keeps the smallest set of tokens whose probability reaches \(p\); renormalize after filtering; repetition penalties would adjust logits before all of this.

    Byte-pair encoding¶

    def train_bpe(word_counts, num_merges):
    """word_counts: {"low": 5, ...}. Returns the list of merges, most frequent pair first."""
    vocab = {tuple(word): count for word, count in word_counts.items()}
    merges = []
    for _ in range(num_merges):
        pairs = Counter()
        for symbols, count in vocab.items():
            for a, b in zip(symbols, symbols[1:]):
                pairs[(a, b)] += count
        if not pairs:
            break
        best = max(pairs, key=lambda p: (pairs[p], p))   # ties broken deterministically
        merges.append(best)
        new_vocab = {}
        for symbols, count in vocab.items():
            out, i = [], 0
            while i < len(symbols):
                if i < len(symbols) - 1 and (symbols[i], symbols[i + 1]) == best:
                    out.append(symbols[i] + symbols[i + 1]); i += 2
                else:
                    out.append(symbols[i]); i += 1
            new_vocab[tuple(out)] = count
        vocab = new_vocab
    return merges

    Say: each iteration counts adjacent pairs weighted by word frequency and merges the most frequent; real tokenizers work on bytes, pre-split text on whitespace and punctuation, and use efficient data structures; to encode new text, apply the merges in the learned order.

    Metrics¶

    def precision_recall_f1(y_true, y_pred):
    tp = np.sum((y_pred == 1) & (y_true == 1))
    fp = np.sum((y_pred == 1) & (y_true == 0))
    fn = np.sum((y_pred == 0) & (y_true == 1))
    precision = tp / (tp + fp) if tp + fp else 0.0
    recall = tp / (tp + fn) if tp + fn else 0.0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0
    return precision, recall, f1


def roc_auc(y_true, scores):
    """Probability a random positive outranks a random negative (ties count half)."""
    pos, neg = scores[y_true == 1], scores[y_true == 0]
    greater = (pos[:, None] > neg[None, :]).sum()
    ties = (pos[:, None] == neg[None, :]).sum()
    return (greater + 0.5 * ties) / (len(pos) * len(neg))


def ndcg_at_k(relevances, k):
    """relevances: graded relevance of results in ranked order."""
    rel = np.asarray(relevances, dtype=float)
    discounts = 1 / np.log2(np.arange(2, k + 2))
    dcg = np.sum(rel[:k] * discounts[: len(rel[:k])])
    ideal = np.sort(rel)[::-1][:k]
    idcg = np.sum(ideal * discounts[: len(ideal)])
    return dcg / idcg if idcg > 0 else 0.0

    Say: guard against division by zero; this AUC is the pairwise definition, \(O(n_{pos} \cdot n_{neg})\); the \(O(n \log n)\) version ranks all scores and uses the Mann–Whitney formula \(\frac{R_{pos} - n_{pos}(n_{pos}+1)/2}{n_{pos}\,n_{neg}}\), where \(R_{pos}\) is the sum of positive ranks; NDCG divides by the ideal ordering's DCG.

    Cosine similarity retrieval¶

    def top_k_cosine(query, doc_matrix, k=3):
    """query: (d,), doc_matrix: (n, d). Returns indices and scores of the k most similar docs."""
    q = query / np.linalg.norm(query)
    D = doc_matrix / np.linalg.norm(doc_matrix, axis=1, keepdims=True)
    scores = D @ q
    idx = np.argsort(-scores)[:k]
    return idx, scores[idx]

    Say: normalize once at indexing time so retrieval is a single matrix–vector product; argpartition gives the top \(k\) in \(O(n)\) before sorting just those; beyond about a million documents, use an ANN index; for RAG, add BM25 and a reranker.
